Definition 2.3.5 The Set of Set Maps.

If \(F\) is a field and \(X\) is a set, then the set of all set maps from \(X\) to \(F\)
🔗
\begin{equation*} \mathcal{F}(X,F):= \{f \ | \ f:X\to F\} \end{equation*}
comes with two binary operations:
🔗
  1. (Addition.) If \(f,g\in \mathcal{F}(X,F)\text{,}\) then \(f+g\) denotes the new function defined by the rule: if \(x\in X\text{,}\) then \((f+g)(x):=f(x)+g(x)\text{.}\)
    🔗
    🔗
  2. (Scaling.) If \(c\in F\) and \(f\in \mathcal{F}(X,F)\text{,}\) then \(cf\) denotes the new function define by the rule: if \(x\in X\text{,}\) then \((cf)(x):=c(f(x))\text{.}\)
    🔗
    🔗
