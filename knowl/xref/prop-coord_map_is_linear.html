Proposition 3.7.2 The coordinate map is linear.

If \(V\) is a finite dimensional vector space over \(F\) and \(\mathcal{B}=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset V\) is an ordered basis, then the coordinate map associated to \(\mathcal{B}\text{,}\) \(\Coord_{\mathcal{B}}:V\to F^n\text{,}\) is a linear map.
