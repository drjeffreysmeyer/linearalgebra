Definition 2.3.3 The Set of Sequences.

If \(F\) is a field, then the set of infinite sequences
🔗
\begin{equation*} F^\infty:=F^{\Z_+}= \left\{(v_1,v_2, \ldots, v_n, \ldots )\ | \ v_i\in F \text{ for all } i\in \Z_+\right\} \end{equation*}
comes with two binary operations:
🔗
\begin{equation*} +:\ F^\infty\times F^\infty \to F^\infty \hspace{3pc} (v_1,v_2, \ldots ) + (w_1,w_2, \ldots ) \mapsto (v_1+w_1,v_2+w_2, \ldots ) \end{equation*}
\begin{equation*} \cdot:\ F\times F^\infty \to F^\infty \hspace{3pc} c\cdot (v_1,v_2, \ldots ) \mapsto (cv_1,cv_2, \ldots ) \end{equation*}
We will say that addition and scaling are done entry-by-entry.
