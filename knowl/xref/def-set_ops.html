Definition 1.1.5 Set Operations.

Let \(X\) and \(Y\) be sets.
🔗
  1. Intersection, denoted \(X\cap Y\text{,}\) is the set of all elements in \(X\) and \(Y\text{.}\) In symbols,
    🔗
    \begin{equation} X\cap Y = \{x \ | \ x\in X \text{ and } x\in Y\}.\tag{1.1.1} \end{equation}
    🔗
  2. Union, denoted \(X\cup Y\text{,}\) is the set of all elements in \(X\) or \(Y\text{.}\) In symbols,
    🔗
    \begin{equation} X\cup Y = \{x \ | \ x\in X \text{ or } x\in Y\}.\tag{1.1.2} \end{equation}
    🔗
  3. Difference, denoted \(X-Y\) or \(X\backslash Y\text{,}\) is the set of all elements in \(X\) but not \(Y\text{.}\) In symbols,
    🔗
    \begin{equation} X- Y = \{x \ | \ x\in X \text{ and } x\notin Y\}.\tag{1.1.3} \end{equation}
    🔗
  4. Cartesian product, denoted \(X\times Y\text{,}\) is the set of pairs of elements in \(X\) and \(Y\text{.}\) In symbols,
    🔗
    \begin{equation} X\times Y = \{ (x,y) \ | \ x\in X \text{ and } y\in Y\}.\tag{1.1.4} \end{equation}
    🔗
