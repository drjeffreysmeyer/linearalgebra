Definition 2.10.2 Injection, Surjection, Bijection.

If \(X\) and \(Y\) are sets and \(f:X\to Y\) is a set maps, then:
🔗
  1. \(f\) is an injection (a.k.a one-to-one) if whenever \(x_1,x_2\in X\) are such that \(f(x_1)=f(x_2)\text{,}\) then \(x_1=x_2\text{.}\)
    🔗
    🔗
  2. \(f\) is a surjection (a.k.a onto) if for each \(y\in Y\text{,}\) there exists an \(x\in X\) such that \(f(x)=y\text{.}\)
    🔗
    🔗
  3. \(f\) is a bijection (a.k.a set isomorphism) if \(f\) is both injective and surjective.

    🔗
