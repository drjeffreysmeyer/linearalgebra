Definition 3.1.5 Mixture Map.

If \(V\) is a vector space over \(F\) and \(S=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset V\) is a finite ordered collection of vectors, then the set map
🔗
\begin{equation*} \Mix_S: F^n \to V, \ \ \ \begin{bmatrix} x_1\\ \vdots \\x_n\end{bmatrix} \mapsto x_1\vect{v}_1+ \cdots + x_n\vect{v}_n \end{equation*}
is the mixture map associated to \(S\text{.}\)
