Definition 3.2.5 Kernel.

If \(T:V\to W\) is a linear map, then the kernel (a.k.a. null space) of \(T\) is the preimage of the trivial subspace. In symbols,
🔗
\begin{equation*} \mathrm{ker}(T):= \mathrm{Null}(T) := T^{-1}(\vect{0}_W) = \{\vect{v}\in V \ | \ T(\vect{v}) = \vect{0}_W\}. \end{equation*}
