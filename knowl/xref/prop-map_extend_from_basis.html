Proposition 3.4.1 Extend a map linearly from a map on the basis.

If \(V\) is a finite dimensional vector space with ordered basis, \(\mathcal{B}=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset V\) , \(W\) is a vector space, and \(T_0:\mathcal{B}\to W\) is a set map, then there exists a linear map \(T:V\to W\) such that for each \(\vect{v}_i\in \mathcal{B}\text{,}\) \(T(\vect{v}_i)= T_0(\vect{v}_i)\text{.}\)
