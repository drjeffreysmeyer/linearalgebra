Definition 2.8.1 Linearly Dependent and Linearly Independent.

If \(V\) is a vector space over \(F\) and \(S\subset V-\{\vect{0}\}\) is nonempty, then the collection is linearly dependent if there exists a nontrivial linear combination of vectors in \(S\) to obtain the zero vector. In symbols, \(S\) is dependent if there exists \(\vect{v}_1,\ldots, \vect{v}_n\in S\text{,}\) \(x_1,\ldots,x_n\in F\text{,}\) not all of which are zero, such that
🔗
\begin{equation*} x_1\vect{v}_1+\cdots x_n\vect{v}_n=\vect{0}. \end{equation*}
If the only way to produce the zero vector is via the trivial linear combination, then \(S\) is linearly independent.
