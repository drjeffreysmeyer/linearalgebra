Definition 2.1.2 Linear Combination.

If \(S = \{\vect{v}_1,\ldots, \vect{v}_n\}\subset V\text{,}\) then a linear combination of \(S\) is an expression of the form
🔗
\begin{equation*} x_1\vect{v}_1+\cdots +x_n\vect{v}_n, \end{equation*}
where \(x_1,x_2,\ldots, x_n\in F\text{.}\)
🔗
The trivial linear combination is the one with all 0 scalars. Otherwise it is nontrivial.
