Definition 3.8.1 Matrix Multiplication (Matrix with Vector).

If \(S=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset F^m\text{,}\) then the \(m\times n\) grid \(A_S:=[\vect{v}_1| \cdots | \vect{v}_n]\) is a matrix. The vectors of \(S\) form the columns of \(A_S\text{.}\) Given scalars \(x_1,\ldots, x_n\in F\text{,}\) matrix multiplication is the linear combination
🔗
\begin{equation} A_S\vect{x}=[\vect{v}_1| \cdots| \vect{v}_n]\begin{bmatrix}x_1\\\vdots \\x_n\end{bmatrix}:=x_1\vect{v}_1+\cdots x_n\vect{v}_n.\tag{3.8.1} \end{equation}
In other words, multiplication by \(A_S\) is the mixture map \(\Mix_S\text{,}\) i.e. \(\Mix_S(\vect{x})=A_S\vect{x}\text{.}\)
