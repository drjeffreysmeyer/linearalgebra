Definition 1.2.1 Field.

A field is a set \(F\) with two operations, addition and multiplication:
🔗
\begin{equation*} F\times F \to F;\ (a,b)\mapsto a+b \hspace{4pc} F\times F \to F;\ (a,b)\mapsto a b \end{equation*}
satisfying:
🔗
  1. Addition and multiplication are associative: If \(a,b,c \in F\text{,}\) then \((a+b)+c=a+(b+c)\) and \((ab)c=a(bc)\text{.}\)
    🔗
    🔗
  2. There exist additive and multiplicative identities: There exists an element \(0\in F\) such that if \(a\in F\text{,}\) then \(0+a=a\text{.}\) There exists an element \(1\in F^\times := F-\{0\}\) such that if \(a\in F^\times\text{,}\) then \(1a=a\text{.}\)
    🔗
    🔗
  3. There exist additive and multiplicative inverses: If \(a\in F\text{,}\) then there exists an element \(b\in F\) such that \(a+(b)=0\text{.}\) If \(a\in F^\times\text{,}\) then there exists an element \(b\in F^\times\) such that \(ab=1\text{.}\)
    🔗
    🔗
  4. Addition and multiplication are commutative: If \(a,b \in F\text{,}\) then \(a+b=b+a\) and \(ab=ba\text{.}\)
    🔗
    🔗
  5. Addition and multiplication are tied together with distributivity: If \(a,b,c \in F\text{,}\) then \(a(b+c)=ab+ac\text{.}\)
    🔗
    🔗
