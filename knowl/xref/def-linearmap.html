Definition 3.1.1 Linear Map.

If \(V\) and \(W\) are vector spaces over the field \(F\text{,}\) then a linear map (a.k.a. linear transformation) from \(V\) to \(W\) is a set map \(T:V\to W\) satisfying:
🔗
  1. (Preserves addition) \(T(\vect{v}_1+\vect{v}_2) = T(\vect{v}_1) + T(\vect{v}_2)\) for all \(\vect{v}_1, \vect{v}_2\in V\text{.}\)
    🔗
    🔗
  2. (Preserves scaling) \(T(k\vect{v}) = k T(\vect{v})\) for all \(k\in F\) and \(\vect{v}\in V\text{.}\)
    🔗
    🔗
