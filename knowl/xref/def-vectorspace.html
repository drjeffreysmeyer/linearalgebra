Definition 2.1.1 Vector Space.

If \(F\) is a field, then a vector space over \(F\) is a set \(V\) with two maps which we call addition (\(+\)) and scaling \(\cdot\text{:}\)
🔗
\begin{equation*} V\times V \to V;\ (\vect{v},\vect{w})\mapsto \vect{v}+\vect{w} \hspace{4pc} F\times V \to V;\ (a,\vect{v})\mapsto a\cdot \vect{v} \end{equation*}
satisfying:
🔗
  1. Addition is associative: If \(\vect{u},\vect{v},\vect{w}\in V\text{,}\) then \((\vect{u}+\vect{v})+\vect{w} = \vect{u}+(\vect{v}+\vect{w})\text{.}\)
    🔗
    🔗
  2. Addition has an identity (which we call a zero vector): There exists an element \(\vect{0}_V\in V\) such that if \(\vect{v}\in V\text{,}\) then \(\vect{0}_V+\vect{v} = \vect{v}\text{.}\)
    🔗
    🔗
  3. Addition has inverses: If \(\vect{v}\in V\text{,}\) then there exists and element \(\vect{w}\in V\) such that \(\vect{v}+\vect{w}=\vect{0}_V\text{.}\)
    🔗
    🔗
  4. Addition is commutative: If \(\vect{v},\vect{w}\in V\text{,}\) then \(\vect{v}+\vect{w} = \vect{w}+\vect{v}\text{.}\)
    🔗
    🔗
  5. Scaling is associative: If \(a,b\in F\) and \(\vect{v}\in V\text{,}\) then \(a\cdot (b \cdot \vect{v}) = (ab)\cdot \vect{v}\text{.}\)
    🔗
    🔗
  6. Scaling has an identity: If \(1\in F\) is the multiplicative identity and \(\vect{v}\in V\text{,}\) then \(1\cdot \vect{v} = \vect{v}\text{.}\)
    🔗
    🔗
  7. Distributivity of scaling 1: If \(a,b\in F\) and \(\vect{v}\in V\text{,}\) then \((a+b)\cdot \vect{v} = a\cdot \vect{v} + b \cdot \vect{v}\text{.}\)
    🔗
    🔗
  8. Distributivity of scaling 2: If \(a\in F\) and \(\vect{v},\vect{w}\in V\text{,}\) then \(a \cdot (\vect{v}+\vect{w}) = a\cdot \vect{v} + a \cdot \vect{w}\text{.}\)
    🔗
    🔗
Elements of a vector space are called vectors. Elements of \(F\) are called scalars.
