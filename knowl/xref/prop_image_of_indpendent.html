Proposition 3.3.2 The image of an independent set is independent.

If \(T:V\to W\) is an injective linear map and \(S=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset V-\{\vect{0}\}\) is a linearly independent set, then \(T(S):=\{T(\vect{v}_1),\ldots, T(\vect{v}_n)\}\subset W\) is a linearly independent set.
