Definition 2.11.1 Cardinality and Finite.

If \(n\in\Z_+\text{,}\) then a set \(X\) has cardinality \(n\) if there exists a bijection \(f:X\to \{1,2,\ldots, n\}\text{.}\) If such an \(n\) exists, \(X\) is finite and we write \(|X|=n\text{.}\) If no such bijection exists for any \(n\in\Z_+\text{,}\) then \(X\) is infinite.
