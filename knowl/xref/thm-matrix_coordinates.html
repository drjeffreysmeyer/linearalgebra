Theorem 3.9.1 Matrix Theorem.

If \(\mathcal{B}\subset V\) and \(\mathcal{C}\subset W\) are bases and \(T:V\to W\) is a linear map, then there exists a unique \(m\times n\) matrix \([T]_{\mathcal{B},\mathcal{C}}\) such that, for all \(\vect{v}\in V\text{,}\)
🔗
\begin{equation} [T]_{\mathcal{B},\mathcal{C}}[\vect{v}]_{\mathcal{B}}=[T(\vect{v})]_{\mathcal{C}}.\tag{3.9.1} \end{equation}
Furthermore, this matrix can be calculated by finding the \(\mathcal{C}\)-coordinates of the images of each \(\mathcal{B}\)-basis vector, i.e. if \(\mathcal{B}= \{\vect{v}_1,\ldots , \vect{v}_n\}\text{,}\) then
🔗
\begin{equation} [T]_{\mathcal{B},\mathcal{C}} = \bigg[ \ [T(\vect{v}_1)]_\mathcal{C} \ \bigg| \cdots \ \bigg| \ [T(\vect{v}_n)]_\mathcal{C}\bigg].\tag{3.9.2} \end{equation}
