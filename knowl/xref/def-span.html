Definition 2.7.1 Span.

The span of \(S\text{,}\) denoted \(\spn(S)\text{,}\) is the set of all linear combinations of vectors in \(S\text{.}\) (Note that \(S\) can be infinite, but the combinations are finite.) In symbols,
🔗
\begin{equation*} \spn(S) := \{x_1\vect{v}_1+\cdots +x_n\vect{v}_n \ | \ \vect{v}_1,\ldots, \vect{v}_n\in S \text{ and } x_1,x_2,\ldots, x_n\in F\}. \end{equation*}
We define the span of the empty set to be the trivial subspace.
