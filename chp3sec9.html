    Section 3.9 Matrix Theorem

    You showed that matrix transformations are linear maps. The surprising and powerful result you will prove in this investigation is, upon choosing coordinates, every linear map between finite dimensional vector spaces is a matrix transformation.
    🔗

    Theorem 3.9.1 Matrix Theorem.

    If \(\mathcal{B}\subset V\) and \(\mathcal{C}\subset W\) are bases and \(T:V\to W\) is a linear map, then there exists a unique \(m\times n\) matrix \([T]_{\mathcal{B},\mathcal{C}}\) such that, for all \(\vect{v}\in V\text{,}\)
    🔗
    \begin{equation} [T]_{\mathcal{B},\mathcal{C}}[\vect{v}]_{\mathcal{B}}=[T(\vect{v})]_{\mathcal{C}}.\tag{3.9.1} \end{equation}
    Furthermore, this matrix can be calculated by finding the \(\mathcal{C}\)-coordinates of the images of each \(\mathcal{B}\)-basis vector, i.e. if \(\mathcal{B}= \{\vect{v}_1,\ldots , \vect{v}_n\}\text{,}\) then
    🔗
    \begin{equation} [T]_{\mathcal{B},\mathcal{C}} = \bigg[ \ [T(\vect{v}_1)]_\mathcal{C} \ \bigg| \cdots \ \bigg| \ [T(\vect{v}_n)]_\mathcal{C}\bigg].\tag{3.9.2} \end{equation}
    🔗

    Hint.
    Try a direct proof. Begin by proving existence. Carefully show that the matrix \([T]_{\mathcal{B},\mathcal{C}}\) in (3.9.2) satisfies (3.9.1). To do this, you may find it useful to expand \(\vect{v}\) relative to \(\mathcal{B}\text{,}\) apply \(T\text{,}\) and then \(\mathcal{C}\)-coordinates. Next show uniqueness by supposing that, if matrix \(A:=[\vect{w}_1| \cdots|\vect{w}_n]\) satisfies (3.9.1) (i.e. \(A[\vect{v}]_{\mathcal{B}}=[T(\vect{v})]_{\mathcal{C}}\)), then \(A=[T]_{\mathcal{B},\mathcal{C}}\text{.}\) To do this, reason about \(A[\vect{v}_i]_{\mathcal{B}}\) and \([T]_{\mathcal{B},\mathcal{C}}[\vect{v}_i]_{\mathcal{B}}\) and deduce that, for each \(i\text{,}\) \(\vect{w}_i=[T(\vect{v}_i)]_\mathcal{C}\text{.}\) You may find Definition 3.7.1, Proposition 2.13.4, Definition 3.1.1, Proposition 3.7.2, Definition 3.8.1, Definition 3.8.1, Definition 3.1.5, and Proposition 3.4.3 useful.

    Corollary 3.9.2.

    If \(T:F^n\to F^n\) is a matrix transformation with associated matrix \(A\text{,}\) and \(\mathcal{B}\subset F^n\) is an ordered basis, then \(A=P_\mathcal{B}BP^{-1}_{\mathcal{B}}\) where \(B:= [T]_{\mathcal{B},\mathcal{B}}\text{.}\)
    🔗
    🔗

    Definition 3.9.3 Similar Matrix Decomposition.

    If \(A=PBP^{-1}\text{,}\) then this is a similar matrix decomposition (SMD) of \(A\) and we say \(A\) and \(B\) are similar.
    🔗
    🔗
    A major goal of future investigations will be to find “good” bases relative to which matrices have a “nice” similar matrix decomposition.
    🔗

    Discussion 3.9.4.

    As stated earlier, the highlight of this section is, you have shown that, upon choosing coordinates, every linear map is a matrix transformation. With that in mind, in a few paragraphs, address each of the following prompts.
    🔗
    1. If every linear map is a matrix transformation, why work with linear maps at all? Why not just work with matrix transformations?
      🔗

    2. If our goal is to understand linear maps, what does the Matrix Theorem tell us about the significance of choosing bases? How can bases be understood as a problem solving strategy in this context?
