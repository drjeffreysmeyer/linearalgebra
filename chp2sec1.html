    Section 2.1 Definition

    In your first course in linear algebra, you worked with \(\R^n\text{,}\) length \(n\) lists of real numbers. We called such lists vectors. We were able to mix vectors, or more precisely, add and scale vectors. These mixing properties allowed us to construct the concepts and tools of matrix algebra over \(\R\text{:}\) matrix equations, bases, decompositions, eigentheory, and more.
    🔗
    We return to \(\R^n\) in the context of linear algebra, to perform structural abstraction and give life to an (abstract) vector space over a field.
    🔗
    (I am trusting that you are comfortable with the concepts and tools from working with \(\R^n\) in your first course in linear algebra. This familiarity provides motivation, intuition, examples, and more generally, a robust concept image for what follows. I encourage you to consult my Concepts of Linear Algebra (COLA) text. Engage with the exposition, play with the GeoGebra manipulatives, and work out the homeworks.)
    🔗

    Definition 2.1.1 Vector Space.

    If \(F\) is a field, then a vector space over \(F\) is a set \(V\) with two maps which we call addition (\(+\)) and scaling \(\cdot\text{:}\)
    🔗
    \begin{equation*} V\times V \to V;\ (\vect{v},\vect{w})\mapsto \vect{v}+\vect{w} \hspace{4pc} F\times V \to V;\ (a,\vect{v})\mapsto a\cdot \vect{v} \end{equation*}
    satisfying:
    🔗
    1. Addition is associative: If \(\vect{u},\vect{v},\vect{w}\in V\text{,}\) then \((\vect{u}+\vect{v})+\vect{w} = \vect{u}+(\vect{v}+\vect{w})\text{.}\)
      🔗
      🔗
    2. Addition has an identity (which we call a zero vector): There exists an element \(\vect{0}_V\in V\) such that if \(\vect{v}\in V\text{,}\) then \(\vect{0}_V+\vect{v} = \vect{v}\text{.}\)
      🔗
      🔗
    3. Addition has inverses: If \(\vect{v}\in V\text{,}\) then there exists and element \(\vect{w}\in V\) such that \(\vect{v}+\vect{w}=\vect{0}_V\text{.}\)
      🔗
      🔗
    4. Addition is commutative: If \(\vect{v},\vect{w}\in V\text{,}\) then \(\vect{v}+\vect{w} = \vect{w}+\vect{v}\text{.}\)
      🔗
      🔗
    5. Scaling is associative: If \(a,b\in F\) and \(\vect{v}\in V\text{,}\) then \(a\cdot (b \cdot \vect{v}) = (ab)\cdot \vect{v}\text{.}\)
      🔗
      🔗
    6. Scaling has an identity: If \(1\in F\) is the multiplicative identity and \(\vect{v}\in V\text{,}\) then \(1\cdot \vect{v} = \vect{v}\text{.}\)
      🔗
      🔗
    7. Distributivity of scaling 1: If \(a,b\in F\) and \(\vect{v}\in V\text{,}\) then \((a+b)\cdot \vect{v} = a\cdot \vect{v} + b \cdot \vect{v}\text{.}\)
      🔗
      🔗
    8. Distributivity of scaling 2: If \(a\in F\) and \(\vect{v},\vect{w}\in V\text{,}\) then \(a \cdot (\vect{v}+\vect{w}) = a\cdot \vect{v} + a \cdot \vect{w}\text{.}\)
      🔗
      🔗
    Elements of a vector space are called vectors. Elements of \(F\) are called scalars.
    🔗
    🔗
    To help distinguish vectors from scalars, when writing by hand, I will put an arrow (e.g. \(\overrightarrow{v}\)) over each vector, and when \(\LaTeX\) ing, I will always use \vect{} for each vector. When \(V\) is clear from context, I will write \(\vect{0}\) instead of \(\vect{0}_V\text{.}\)
    🔗

    Definition 2.1.2 Linear Combination.

    If \(S = \{\vect{v}_1,\ldots, \vect{v}_n\}\subset V\text{,}\) then a linear combination of \(S\) is an expression of the form
    🔗
    \begin{equation*} x_1\vect{v}_1+\cdots +x_n\vect{v}_n, \end{equation*}
    where \(x_1,x_2,\ldots, x_n\in F\text{.}\)
    🔗
    The trivial linear combination is the one with all 0 scalars. Otherwise it is nontrivial.
    🔗
    🔗
    Note that we only take finite sums in linear combinations.
    🔗
