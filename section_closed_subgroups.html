    Section 2.3 Closed Subgroups

    In this section we introduce closed subgroups of Lie groups. As usual, we start with understanding the closed subgroups for matrix groups, extract their properties and then construct and analyze the formal object.
    🔗
    

    Subsection 2.3.1 Closed Subgroups of Matrix Lie Groups

    We know \(\GL_n(\R)\) is a Lie group. We also know that \(\SL_n(\R)\) is a closed subgroup of \(\GL_n(\R)\text{.}\) In this section we will show that \(\SL_n(\R)\) is a Lie group. We will also show that the orthogonal group \(\O_n(\R)\) is a closed subgroup of \(\GL_n(\R)\) and that it is a Lie group. Finally, we will show that the special orthogonal group \(\SO_n(\R)\) is a closed subgroup of \(\O_n(\R)\) and that it is a Lie group.
    🔗
    Polynomials are continuous functions. The set of zeros of a continuous function is closed. Therefore, the set of zeros of a polynomial is closed. The determinant function is a polynomial function. Therefore, the set of matrices with determinant equal to one is closed. This shows that \(\SL_n(\R)\) is a closed subgroup of \(\GL_n(\R)\text{.}\)
    🔗
    Let \(q:\R^{n}\to\R\) be a quadratic form. The set of matrices \(A\) such that \(q(Ax)=q(x)\) for all \(x\in\R^n\) is closed. This shows that orthogonal group \(\O(q)\) is a closed subgroup of \(\GL_n(\R)\text{.}\)
    🔗

    Subsection 2.3.2 Cartan’s Theorem

    Definition 2.3.1 Embedded Lie Subgroup.

    If \(G\) is a Lie group, then a subset \(H \subset G\) is an embedded Lie subgroup of \(G\) if \(H\) is an embedded submanifold of \(G\) and the restriction of the Lie group structure of \(G\) to \(H\) makes \(H\) a Lie group.
    🔗
    🔗

    Proposition 2.3.2.

    If \(G\) is a Lie group and \(H \subset G\) is an embedded Lie subgroup, then \(H\) is closed in \(G\text{.}\)
    🔗
    🔗

    Hint.
    Use the fact that an embedded submanifold is closed.

    Proposition 2.3.3 The Vector Subspace associated with a Closed Subgroup.

    If \(G\) is a Lie group and \(H \subset G\) is a closed subgroup, then the set
    \begin{equation*} \mathfrak{h}:=\{X\in\mathfrak{g}: \exp(tX)\in H \text{ for all } t\in\R\} \end{equation*}
    is a vector subspace of \(L(G)\text{.}\)

    Theorem 2.3.4 Closed Subgroups are Embedded Lie Subgroups. (Cartan)

    If \(G\) is a Lie group and \(H \subset G\) is a closed subgroup, then \(H\) is an embedded Lie subgroup of \(G\text{.}\)
